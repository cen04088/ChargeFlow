# 상단 간소화 + 고속도로 화면 지도 중심 개편 — 설계

작성일: 2026-11-19 · 앞선 설계: `2026-11-19-nearby-sheet-design.md`(홈의 지도 + 시트)

## 왜

홈을 "지도 + 끌어 올리는 목록"으로 바꾼 뒤 이용자가 두 가지를 요청했다.

1. 홈 상단에서 지역 선택 · 충전 규격 · 고속도로 버튼만 남기고 나머지(제목, 설명)는 없앤다.
2. 고속도로 화면도 같은 방식으로, 지도 중심으로 직관적이게 바꾼다.

이용자는 시안 세 화면(홈 상단, 고속도로, 휴게소)을 보고 **세 가지 모두** 하기로 했다. 시안: `.superpowers/brainstorm/566-1795062807/content/highway-map-redesign.html`.

지금 고속도로 쪽은 고속도로 홈(가는 길 휴게소 찾기 · 즐겨찾기 · 최근 · 노선 목록) → 노선별 휴게소 목록 → 휴게소 상세로 세 번 들어가는 목록 화면이다. 이용자의 절반 가까이가 50·60대다.

## 목표 · 하지 않는 것 · 실패 조건

**목표**
- 홈, 고속도로, 휴게소 세 화면이 같은 조작법을 쓴다: 위에서 고르고, 지도에서 보고, 아래 시트에서 결정한다.
- 고속도로는 노선을 고르면(또는 자동으로 골라지면) 지도에 노선과 휴게소가 바로 보인다. 화면 수가 셋에서 둘로 준다.
- 휴게소 화면은 접힌 시트만 봐도 "기다릴지, IC로 나갈지"의 결론과 길찾기가 나온다.

**하지 않는 것**
- 서버 변경. 지금 API(`highways`, `nodes`, `nearest-ra`, `bypass-stations`, `pattern`, `me/*`, `notify-me`)로 한다.
- 구간 미리 보기(`/trip`) 화면 자체의 개편. 들어가는 입구만 옮긴다.
- 실제 도로 모양의 노선 선. IC·휴게소 좌표를 이은 선으로 그린다.
- 새 기능(경로 계획, 요금 등).

**실패 조건**
- 지금 있는 기능이 사라진다: 즐겨찾기(+알림 동의), 최근 본 휴게소, 공유, 방향 전환, 휴게소 이름 검색, 구간 미리 보기 입구, IC 앞/뒤 선택, 필터(충전 규격·100kW 이상·24시간), 30분 거리까지 넓혀 찾기, 추천 충전소와 길찾기, 요일별 혼잡 패턴, 1분 자동 갱신, 안내 문구(공공데이터·직선거리).
- 기존 링크가 깨진다: `/highways`, `/highway/:code?dir=`, `/rest-area/:id`, `/trip`, `/?ra=`, 공유 링크 `intoss://chargeflow/rest-area/:id`.
- 끌 줄 모르는 사람이 목록에 못 들어간다(시트 진입 버튼이 없다).
- 지도를 못 불러오거나 화면이 낮을 때 막다른 화면이 된다.
- 색만으로 상태를 구분한다.

## 검토한 방식

| 방식 | 내용 | 결론 |
|---|---|---|
| 홈의 시트·지도 구조를 그대로 재사용 | `NearbyListSheet`(이미 내용과 무관한 범용 시트)를 세 화면이 같이 쓰고, 고속도로용 지도 컴포넌트를 새로 둔다 | **채택** |
| 고속도로 화면만 지도, 휴게소는 그대로 | 작업이 작다 | 이용자가 세 화면 모두를 골랐다 |
| 세 화면을 한 화면으로(지도 하나에 모드 전환) | 화면 전환이 없다 | 주소(링크)·뒤로가기가 깨지고 상태가 너무 복잡해진다 |

## 설계

### 1. 홈 상단
- `PageHeading`(제목 "주변 급속충전소", 설명)을 화면에서 없앤다. 버튼 줄(지역 선택 · 충전 규격 · 고속도로)은 그대로.
- 화면낭독기를 위해 `h1`은 보이지 않게 남긴다(시각적으로만 숨김).
- 지도 배치·쌓인 배치·지역 선택 화면 모두에 적용한다.

### 2. 고속도로 화면 (`/highways`, `/highway/:code?dir=`)
두 경로가 같은 화면을 쓴다. `/highway/:code`는 그 노선을 보여 주고, `/highways`는 노선을 정해서 `/highway/:code?dir=`로 바꿔 준다(뒤로가기에 남지 않게 replace).

**상단 버튼 줄**
- `[노선 이름]`: 누르면 노선 고르기 시트.
- `[방향]`: 지금 방향 이름(예: "부산 방향"). 누르면 반대 방향으로 바뀐다. 화면낭독기 이름은 "방향 바꾸기, 지금 부산 방향".
- `[주변 충전소]`: 홈(`/`)으로.

**노선 정하기 (`/highways`로 들어왔을 때)**
1. 위치를 받아 `nearest-ra`로 가는 방향 휴게소를 찾는다. 가장 가까운 휴게소가 20km 안이면 그 노선·방향을 고른다.
2. 아니면 마지막에 본 노선·방향(기기에 저장).
3. 그것도 없으면 노선 고르기 시트를 연 채로 시작한다(뒤에는 안내 문구만).
위치 응답은 12초를 넘기면 실패로 본다(홈과 같은 규칙).

**지도**
- 노선 선: 그 방향의 IC·휴게소 좌표를 순서대로 이은 선(브랜드 파랑, 흰 테두리).
- 휴게소 핀(글자 + 색):

| 혼잡도 | 핀 글자 | 색 |
|---|---|---|
| 여유 · 보통 | `N대`(빈 충전기 수) | 초록 |
| 혼잡 | `N대` | 주황 |
| 만석 | `만석` | 주황 |
| 이용 불가 | `이용 불가` | 회색 |
| 정보 없음 | `정보 없음` | 회색 |

- 충전기가 없는 휴게소는 핀을 그리지 않는다(지금 목록과 같은 기준).
- 겹치는 핀은 점으로 줄인다(홈과 같은 규칙). "다음 휴게소"와 선택한 휴게소는 항상 글자 핀.
- 처음에는 내 위치와 다음 휴게소 두세 곳이 보이게 맞춘다. 위치가 없으면 노선 전체가 보이게.
- 핀을 누르면 휴게소 화면으로 간다.

**시트**
- 접힘: 위치가 그 노선 위(가는 방향)면 "다음 휴게소 · 약 12km 앞" + 휴게소 한 줄 + "이후 휴게소 N곳 보기". 아니면 "{방향} 첫 휴게소" + 한 줄 + "휴게소 N곳 보기".
- 펼침: 휴게소 이름 검색, "구간 미리 보기" 한 줄(`/trip?hw=&dir=`), 가는 순서의 휴게소 전체. 줄에는 이름, "약 Nkm 앞"(위치를 알 때) 또는 기점부터 거리, 혼잡 상태.
- 방향을 바꾸거나 노선을 바꾸면 접힌다.

**노선 고르기 시트** (모달)
- 맨 위 "내 위치로 찾기".
- 즐겨찾기 휴게소, 최근 본 휴게소(누르면 휴게소 화면).
- 노선 12개(번호, 이름, 구간).

**고속도로 홈에 있던 "내 차 충전 규격" 타일**은 없앤다. 홈 상단과 휴게소 화면 필터에 이미 있다.

### 3. 휴게소 화면 (`/rest-area/:id`)

**상단 버튼 줄**
- 휴게소 이름과 "노선 · 방향"(글자). 오른쪽에 즐겨찾기, 공유 버튼(지금 동작 그대로).

**지도**
- 휴게소 핀(위 표와 같은 글자·색), 앞뒤 IC 이름표, IC 밖 충전소 핀.
- 충전소 핀 글자: 빈 대수를 알면 `N대 · M분`, 모르면 `M분`(M = 우회하면 더 걸리는 시간). 추천 충전소는 강조.
- 앞 IC — 휴게소 — 뒤 IC를 잇는 선.
- 충전소 핀을 누르면 그 충전소 상세 시트(지금의 `StationSheet`).

**시트 접힘 = 결론**
- 첫 줄(판정):

| 휴게소 상태 | 문구 |
|---|---|
| 만석, 대기 시간 추정 있음 | "휴게소는 만석이에요. 약 N분 기다려야 해요" |
| 만석, 추정 없음 | "휴게소는 만석이에요" |
| 혼잡 | "휴게소가 붐벼요. 빈 충전기 N대" |
| 여유 · 보통 | "휴게소에 빈 충전기가 N대 있어요" |
| 이용 불가 | "휴게소 충전기를 지금 쓸 수 없어요" |
| 정보 없음 | "휴게소 충전기 상태를 받지 못했어요" |

- 둘째 줄: 추천 충전소(지금의 "가장 빨리 다녀올 곳" 규칙 그대로) 한 줄 + "길찾기" 버튼. 추천할 곳이 없으면 "IC 밖 N분 안에는 맞는 충전소가 없어요"와 "30분 거리까지 찾아보기".
- "IC 밖 충전소 N곳 보기" 버튼으로 펼친다.

**시트 펼침 = 지금 화면의 내용 그대로**
- IC 앞/뒤 탭, 필터 칩, 충전소 줄, "N곳 더 보기", 요일별 혼잡 패턴, 안내 문구.

### 공통
- 시트는 홈의 `NearbyListSheet`를 그대로 쓴다(접힘/펼침 두 단계, 손잡이 끌기·누르기·버튼).
- 화면 높이가 560px 미만이거나 지도를 못 불러오면, 지도 없이 지금의 목록 화면처럼 쌓아서 보여 준다(페이지 스크롤). 기능은 모두 닿아야 한다.
- 지도 화면에서는 페이지가 스크롤되지 않는다.
- 상태색은 홈과 같은 토큰(`--state-available/full/unavailable`), 브랜드 파랑은 버튼·노선 선·강조에만.
- 글씨·터치 크기 등은 `frontend/AGENTS.md` 하드 규칙과 홈 기준(이름 17px 이상, 숫자 20px 이상, 핀 15px 이상).

### 기록
- 기존 이름은 유지한다(`highway`, `highway_direction`, `highway_open_rest_area`, `rest_area*`, `best_*`, `station_*`, `home_*` 중 남는 것).
- 새 이름: `highway_pick`(`highway`, `by: "auto"|"last"|"sheet"`), `highway_sheet_toggle`, `rest_area_sheet_toggle`(`open`, `by`).

## 변경: 고속도로 화면은 "내비 고속도로 모드"로 (2026-11-19, 이용자 선택)

노선 지도를 실제로 본 뒤 이용자가 "노선 선과 핀 디자인이 너무 AI 같다"고 했고, 다른 시안 세 가지(표지판 / 내비 고속도로 모드 / 지도 그대로 작은 표식) 중 **B. 내비 고속도로 모드**를 골랐다. 시안: `.superpowers/brainstorm/566-1795062807/content/route-line-alternatives.html`의 가운데 화면. 위 "2. 고속도로 화면"의 지도·시트 부분을 아래로 대체한다. 상단 버튼 줄, 노선 정하기, 노선 고르기 시트, 휴게소 화면(3번)은 그대로다.

**기본 보기 = 노선 띠**
- 노선을 곧은 세로 띠(도로 모양)로 펴고, 가는 순서대로 휴게소와 IC를 정류장처럼 늘어놓는다. 페이지가 세로로 스크롤된다. 시트는 쓰지 않는다.
- 휴게소 줄: 띠 위의 고리(상태색) + 이름 + 둘째 줄(급속 대수 · 확인 시각, 만석이면 대기 추정이 있을 때 함께) + 오른쪽에 상태 단어와 빈 대수. 누르면 휴게소 화면.
- IC 줄: 띠 위의 작은 점 + 이름(작고 옅게). 누를 수 없다.
- 왼쪽 거리 칸: 가는 방향이 확인됐으면 "12km"(내 위치에서 앞으로), 아니면 기점부터 거리.
- 가는 방향이 확인됐으면 맨 위에 "지금 여기" 표시가 있고 그 아래로 앞에 있는 것만 보인다. 지나온 구간은 "지나온 휴게소 N곳 보기"로 접어 둔다. 다음 휴게소 줄은 옅은 바탕으로 강조한다.
- 가는 방향을 모르면 노선 전체를 기점부터 보여 주고, 위치가 노선 근처면 가장 가까운 휴게소 줄로 스크롤하고 "가까운 휴게소"로 표시한다.
- 휴게소 이름 검색은 띠 위에, "구간 미리 보기"와 안내 문구는 띠 아래에 둔다. 검색 중에는 IC 줄을 숨기고 맞는 휴게소만 보인다.

**지도 보기**
- 오른쪽 위 작은 지도 창(노선 모양과 내 위치)을 누르면 지금의 노선 지도 + 시트 화면으로 바뀐다. 거기서 "목록으로 보기"로 돌아온다. 선택은 기기에 기억하지 않는다(들어올 때는 늘 띠).
- 지도를 못 불러오면 작은 지도 창을 숨긴다. 띠는 지도 없이도 완전히 동작한다(쌓인 배치가 따로 필요 없다).

**색**
- 띠(도로)는 주황 계열 도로색으로 그리되 상태색 주황(`--state-full`)과 헷갈리지 않게 명도를 달리하고, 상태는 고리 색 + 글자로 알린다.

## 작성자가 정한 것 (이용자 확인 필요 시 고칠 수 있다)

- 방향은 두 칸 토글 대신 "누르면 반대 방향" 버튼 하나로 했다. 상단 한 줄에 노선·방향·주변 충전소를 다 넣기 위해서다.
- 휴게소 이름 검색은 시안 설명("노선 고르기 시트 안")과 달리 **펼친 목록 맨 위**에 둔다. 지금 검색이 "이 노선의 휴게소"를 거르는 기능이라 그 목록 위가 자연스럽다.
- 자동으로 노선을 고르는 기준 거리는 20km다.
- 고속도로 홈의 "내 차 충전 규격" 타일은 없앤다.

## 검증

- 순수 로직(핀 글자·색, 판정 문구, 다음 휴게소 고르기, 노선 자동 선택, 접힌 줄 내용)은 vitest.
- 화면은 실제 카카오 지도에서 확인한다(로컬에서 가능해졌다): 세 화면 각각 지도·핀·시트 여닫기·지도 실패·낮은 화면.
- 토스 앱 실기기 확인(뒤로가기 쓸기, 위치 권한)은 별도.
