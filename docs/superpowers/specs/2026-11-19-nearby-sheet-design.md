# 주변 충전소 홈: 큰 지도 + 끌어 올리는 목록 — 짧은 설계

작성일: 2026-11-19 · 기준 커밋: `09adf5a` (화면 개편 반영 후)

## 왜

이용자가 레퍼런스 시안 세 가지 중 **B(지도를 크게, 끌어 올리는 목록)**를 골랐다. 지금 홈은 머리말 → 버튼 줄 → 지도(화면의 45%) → 목록이 위아래로 쌓여 있어서 지도가 좁고, 핀은 "빈 곳 = 브랜드색, 그 외 = 회색" 두 가지뿐이라 충전 중과 이용 불가가 구분되지 않는다.

## 목표 · 하지 않는 것 · 실패 조건

**목표**
- 지도가 머리말 아래 남은 화면을 모두 쓰고, 목록은 지도 위에 얹힌 시트로 보인다.
- 핀만 보고 빈 곳·충전 중·이용 불가와 초급속 여부를 알 수 있다.

**하지 않는 것**
- 서버 변경(지금 응답으로 모두 가능하다).
- "차로 몇 분" 표시(길찾기 API가 필요하다).
- 머리말과 버튼 줄(지역 선택 · 충전 규격 · 고속도로)의 재배치. 방금 개편한 그대로 둔다.
- 충전소 상세 시트, 지역 선택 화면, 지도 실패 시 화면의 변경.

**실패 조건**
- 끌어 올리는 동작을 모르는 사람이 두 번째 충전소를 볼 방법을 못 찾는다.
- 시트를 끌 때 지도가 같이 움직이거나, 토스의 뒤로가기 쓸기와 충돌한다.
- 안내 문구(빈 곳 없음, 정보 수신 불가, 지난번 위치)가 접힌 시트에 가려 보이지 않는다.
- 색만으로 상태를 구분한다(색각 이상·저시력).

## 검토한 방식

| 방식 | 내용 | 결론 |
|---|---|---|
| 직접 만든 2단 시트 | 페이지 안의 고정 패널. 접힘/펼침 두 높이, 손잡이 끌기 + 누르기 + 버튼 | **채택** |
| TDS `BottomSheet` | 이미 쓰는 컴포넌트 | 딤이 깔리는 모달이라 뒤의 지도를 만질 수 없다 |
| 3단 시트(살짝/중간/전체) | 애플 지도 방식 | 단계가 많을수록 50·60대에게 어렵다. 목록이 최대 30곳이라 두 단이면 충분하다 |

이용자가 B안을 골랐고, 만드는 방식은 작성자가 골랐다.

## 설계

### 배치
```
┌──────────────────────────┐
│ 주변 급속충전소            │  머리말 (그대로)
│ [지역 선택][충전 규격][고속도로] │  버튼 줄 (그대로)
├──────────────────────────┤
│ [빈 곳 3곳]     [빈 대수|출력] │  지도: 남은 높이 전부
│      ⚡3대                 │
│ (충전 중)   ●              │
│         2대      [내 위치]  │
│╭────────────────────────╮│
││        ━━━             ││  시트(접힘): 손잡이
││ 가장 가까운 빈 곳          ││
││ 영통 공영주차장        3대 ││
││ [ 2곳 더 보기 ]          ││
│╰────────────────────────╯│
└──────────────────────────┘
```

### 시트
- 두 상태: **접힘**(손잡이 + 첫 줄 + "N곳 더 보기" 버튼)과 **펼침**(화면 높이의 약 70%, 안에서 목록이 스크롤).
- 펼치는 방법 세 가지: 손잡이를 위로 끌기, 손잡이 누르기, "N곳 더 보기" 버튼. 접는 방법: 아래로 끌기, 손잡이 누르기, 지도 누르기.
- 끌기는 손잡이 영역에서만 시작한다. 세로 이동만 받고, 놓은 위치가 중간을 넘었는지와 속도로 접힘/펼침을 정한다.
- 펼친 목록에는 지금 목록의 내용이 그대로 들어간다(빈 곳 → 없으면 충전 중인 곳, 확인 시각, 안내 문구). 기존 "N곳 더 보기"의 3곳 제한은 없앤다. 펼치면 전부 보인다.
- 접힌 시트의 첫 줄에 들어가는 것:
  - 평소: "가장 가까운 빈 곳" + 그 충전소.
  - 빈 곳 없음 / 충전소 없음 / 정보 수신 불가 / 지난번 위치 안내: 그 안내 문구의 제목. 정보 수신 불가의 "다시 시도" 버튼도 접힌 상태에서 보인다.
  - 찾는 중: "급속충전소를 찾고 있어요".
- 지도 위 버튼("내 위치", "이 위치에서 찾기")과 카카오 지도의 범위 맞춤 여백은 접힌 시트 높이만큼 위로 올린다.
- 손잡이는 버튼 역할(`aria-expanded`)을 갖고, Enter/Space로 여닫는다.

### 핀
- 색과 글자를 함께 쓴다: 빈 곳 = 초록 + "3대", 충전 중 = 주황 + "충전 중", 이용 불가 = 회색 + "이용 불가". 목록 오른쪽 숫자·문구도 같은 색.
- 브랜드색(파랑)은 버튼·강조에만 쓰고 상태색으로는 쓰지 않는다. (작성자 판단: "빈 곳 = 초록"이 충전 앱에서 통하는 약속이다.)
- 최대 출력 150kW 이상이면 핀 글자 앞에 번개 아이콘. 목록 설명에는 "200kW 초급속".
- 지도 오른쪽 위 토글 "빈 대수 | 출력": 출력을 고르면 핀 글자가 "200kW"로 바뀐다. 색은 그대로 상태를 나타낸다.
- 지도를 축소하면(카카오 레벨 7 이상) 핀을 글자 없는 색 점으로 줄인다. 점도 누를 수 있다.

### 그대로 두는 것
- 지역 선택 화면, 오류 화면: 지도와 시트 없이 지금처럼.
- 지도를 못 불러왔을 때: 시트 없이 지금의 쌓인 목록.
- 충전소를 누르면 뜨는 상세 시트(TDS 모달).

### 기록
- `nearby_sheet_toggle`(`open: 0|1`, `by: "drag"|"handle"|"button"|"map"`), `nearby_pin_mode`(`mode: "count"|"power"`). 기존 `nearby_more`는 버튼으로 펼칠 때 계속 남긴다.

## 검증

- 순수 로직(핀 글자·종류 결정, 놓을 때 접힘/펼침 판정, 접힌 줄에 무엇을 보일지)은 vitest.
- 끌기, 지도와의 상호작용, 핀 모양은 브라우저에서 확인해야 한다. **로컬에 카카오 지도 키가 있어야 한다.** 키가 없으면 지도 없는 경로만 확인할 수 있다.
- 토스 앱 안에서 뒤로가기 쓸기와 충돌하지 않는지는 실기기 확인이 필요하다.

## 만드는 사람에게 맡기는 것

- 시트를 별도 컴포넌트로 뺄지, 끌기를 어떤 이벤트(pointer/touch)로 구현할지.
- 초록·주황의 정확한 색 값(대비 4.5:1 이상, 기존 토큰이 있으면 그것).
- 번개 아이콘의 형태(SVG, `currentColor`).
